# Tiện ích dùng chung

`dev_verify.py`: profile phát triển dev_5min cho ba bài, tái sử dụng verifier gốc. Xem [hướng dẫn chấm local](../../docs/LOCAL_GRADING.md). Điểm dev không phải điểm full.

`local_grade.py`: runner cho notebook local, chọn đúng artifact theo track/ID/config và lưu kết quả trực tiếp vào results.
